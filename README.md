
FinTrust Digital Bank Analytics
Data Analytics project for FinTrust Digital Bank - AnalystLab Africa Experience Lab Internship

Project Overview
FinTrust is a fictional digital bank. Goal: understand customer behaviour, transactions, channels, and risk patterns using 1,500 customers and 12,000 transactions (Jan-Mar 2026).

Key Findings (Week 2)
- Mobile App: 5,102 transactions (highest channel)
- Everyday segment: 5,644 transactions
- Success Rate: 90.47%
- Risk-Review Rate: 19.6% (not confirmed fraud)

Tools
Python, Pandas, Excel, SQL, Power BI

Repository Structure
- /data - raw data
- /notebooks - Python EDA
- /sql - business questions
- /excel - data cleaning
- /dashboard - Power BI
- /reports - summaries
